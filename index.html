Build a dependable case note documentation process

Move from first capture in a system of engagement to final documentation in a system of record, with enough structure to keep notes findable, timely, and audit-ready.

The main goal is practical: use the "Add case note" iOS shortcut to save a note into OneNote and then open that same note on the desktop. The other details are here to support that outcome, not to make you memorize every technical term.

Complete each learning objective in a module to complete that module. To complete a learning objective, mark it as complete. The Do steps are recommended steps for completing the learning objective, not a separate submission.

Use Edit state if you want to inspect or update what the coach remembers about your progress across learning objectives.

API key setup

Visit the Billing page, turn auto recharge off, and add a small credit to your account, such as $5.

Then create an API key on the API keys page. Copy the secret key value and store it securely.

Progress is saved locally, but the API key is not saved to localStorage. When supported, your browser may offer to store it in its password manager.

Entering an API key activates the Connect sections in the learning objectives below.
